# Анализ продаж по артикулам

## Как запустить

1. Установить Python 3.
2. Установить зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Поместить `sales.csv` в корневую папку проекта.
4. Запустить скрипт:

   ```bash
   python main.py
   ```

Результат будет сохранён в файл `daily_by_sku.csv` в той же папке.

## Как проверяли расчёты

Проверял результат на отдельных артикулах и датах: сравнивал количество уникальных заказов с исходными данными, а выручку — с суммой `quantity × price` только по заказам со статусом `delivered`.

Дополнительно проверял, что повторяющиеся записи не увеличивают количество заказов и выручку, а итоговый файл отсортирован по артикулу и дате.

## Проблемы в данных

Перед запуском необходимо проверить исходный CSV на повторяющиеся строки, пропущенные значения, корректность дат и числовых полей.

Полностью повторяющиеся строки удаляются. Остальные особенности данных требуют отдельной проверки. 

## Использование ИИ-ассистентов

Для подготовки решения использовал ChatGPT: с его помощью разобрал требования и подготовил первоначальный вариант скрипта. Результат и логику расчётов необходимо проверить самостоятельно на исходных данных.

## Что осталось доработать

Решение рассчитано на CSV с колонками `order_id`, `sku`, `order_date`, `status`, `quantity` и `price`. Если структура исходного файла отличается, названия полей нужно адаптировать.

Отдельно стоит проверить, достаточно ли удаления полностью одинаковых строк для устранения дублей в исходной выгрузке.
